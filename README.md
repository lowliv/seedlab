# EENG350 SEED Lab Group 12

## Overview

This repository is the compilation of all the code relevant to SEED Lab and its separate assignments.

## Purpose

The purpose of the final solution to the project is to create a robot that is able to automatically follow a path to each subsequent ArUco marker and properly control itself based on the position and meaning of each marker.
